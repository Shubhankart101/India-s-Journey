About the atlas

Understand the data, not just the line.

The idea behind the atlas

Big change is easier to see, one signal at a time.

India’s story isn’t a single headline or a single number. This independent, public-data project brings together long-run indicators and current snapshots so you can explore what changed, when it changed, and how the evidence is measured.

Start with a theme, search for an indicator and narrow the period. Hover for exact values, zoom into a moment, or open any chart for the full series, notes and cited source. Every chart keeps its frequency and limitations visible; unavailable data is never filled with an estimate.

Reading the numbers

How numbers are shown

Values in U.S. dollars use the international system (thousand, million, billion). Everything else uses the Indian system (lakh, crore).

Pie charts show the largest eleven slices and fold the rest into “Other”. Additive categorical charts can switch between pie and bar views.

Evidence before inference

Public data. Clear provenance.

Each graph links to its underlying source and explains its unit and cadence. Some indicators are annual, some are survey snapshots, and some are assembled from official tables. Read the chart note before comparing unlike measures.

Using the data

Every chart has a CSV download, a data table and a share link in its toolbar. The same data is available from the JSON API.

Save charts with the ★ button; they are kept in this browser. Compare and sign-in are part of the local web app.
