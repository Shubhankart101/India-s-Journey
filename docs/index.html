🧭 About this dashboard

A readable public record of India’s changing signals

This dashboard was created to make India’s economic, social, and infrastructure data easier to explore in one place. It brings together long-run public indicators, preserves the frequency and limitations of each source, and turns the underlying observations into interactive charts rather than static claims.

The project is independent and uses cited public APIs and official portals. It is designed for curiosity, comparison, and context: every graph can be inspected, zoomed, reset, searched, and traced back to its source. Pending cards are intentionally visible only when requested, so missing automated exports are never presented as invented numbers.

With sincere thanks to PolityPolicy and Indian Matrix for the inspiring work that encouraged this visual approach to public information. Indian Matrix especially helped motivate the market-and-public-indicators view. This dashboard is an independent work, created with appreciation for that spirit of public-data storytelling.

🏛️ Inspiration

PolityPolicy and Polity and Policy

This dashboard was directly inspired by PolityPolicy.com's public-data storytelling and by Tushar Gupta's Polity and Policy Substack. This dashboard is an independent, separately-built project; it does not copy or mirror PolityPolicy's interactive chart rendering, and does not represent PolityPolicy or its authors.

The reading rail alongside is populated from the public Polity and Policy RSS snapshot, refreshed weekly by this project's pipeline, so the buttons stay linked to the latest available public articles from that Substack.
