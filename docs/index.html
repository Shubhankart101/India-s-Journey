🧭 About this dashboard

A readable public record of India’s changing signals

This dashboard was created to make India’s economic, social, and infrastructure data easier to explore in one place. It brings together long-run public indicators, preserves the frequency and limitations of each source, and turns the underlying observations into interactive charts rather than static claims.

The project is independent and uses cited public APIs and official portals. It is designed for curiosity, comparison, and context: every graph can be inspected, zoomed, reset, searched, and traced back to its source. Pending cards are intentionally visible only when requested, so missing automated exports are never presented as invented numbers.

With sincere thanks to PolityPolicy, Tushar Gupta’s Polity and Policy Substack, and Indian Matrix for the inspiring work that encouraged this visual approach to public information. Indian Matrix especially helped motivate the market-and-public-indicators view. This dashboard is an independent work, created with appreciation for that spirit of public-data storytelling.
