# Indian Railways

Top-level dashboard group. Built by `scripts/indian_railways_layer.py` from the Railway Board Year Book 2023-24, PIB releases and live World Bank series (most countries stop reporting rail data around 2019). Zone and State route-km tables each reconcile to 69,181 km. Not included because not verified in an official table: zone-level traffic, DFC and Kavach progress, fatalities, staffing, subsidies and production. If a live pull fails, the previous value is kept.
